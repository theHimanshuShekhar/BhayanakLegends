# Public repo doubles as the distribution and auto-update channel

BhayanakLegends is public so GitHub Releases can serve installers, `latest.json`, and Findings Pack assets to unauthenticated installs; LoLTrends (private research) stays closed, and CI copies new pack artifacts into this repo's releases. App updates ship via the Tauri updater pointed at the stable `releases/latest/download/latest.json` URL, built by GitHub Actions with the Tauri CLI and update signatures produced from a keypair whose private half exists only as an Actions secret. The publisher creates a draft through the Releases API, validates and captures its release ID and per-release `upload_url`, uploads the exact updater and Findings Pack asset set through that validated upload endpoint without replacement, and promotes or re-drafts only that captured release ID after authenticated remote validation and anonymous endpoint checks. Private-repo release assets were rejected because they would force an embedded GitHub token into every friend's binary.
