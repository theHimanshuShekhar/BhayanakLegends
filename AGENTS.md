# Bhayanak Legends

Windows 11 League of Legends companion app (Tauri 2 shell + React 19 webview + Python FastAPI sidecar) turning LoLTrends research into personal guidance. Friends-only distribution.

## Read in this order

- [CONTEXT.md](./CONTEXT.md) — domain glossary; use terms verbatim in code and UI copy.
- [docs/CONTRACT.md](./docs/CONTRACT.md) — frozen API/SSE/pack interfaces. `src/api/types.ts` mirrors the backend models; change them together.
- [docs/adr/](./docs/adr/) — architecture decisions; read before proposing anything that contradicts one.

## Verify before claiming done

Run all four; a change is not done while any is red.

1. `cd backend && uv run pytest -q`
2. `pnpm vitest run`
3. `pnpm build`
4. `pnpm exec playwright test` — needs a sidecar on `127.0.0.1:23110` with token `dev` first:
   `cd backend && BHAYANAK_PORT=23110 BHAYANAK_TOKEN=dev uv run python -m bhayanak_legends.sidecar &`
   then seed CI data with `uv run python tools/ci_seed.py` when `data/dev-import/` is absent.

## Guardrails

- **Phrasing discipline** (ADR-0003): only Actionable/a-lite findings may use imperative copy; Diagnostic findings describe. Tests enforce this.
- **Compliance**: never render enemy summoner names in champ select UI; never implement enemy ability/ult timers.
- **Pack**: `pack/findings-pack.v1.json` is generated by `backend/tools/build_pack.py`; every number carries a `source_ref`. Regenerate, never hand-edit.
- **Secrets**: `.env` holds the dev Riot key and is gitignored. Keys never enter code, tests, or logs.

## Gotchas

- The Riot `sea` route 403s the default Python User-Agent; every Riot HTTP call sends a custom UA (`riot_client.py`).
- The sidecar must keep CORS origins for `localhost:1420` and `tauri://localhost` or the webview cannot reach it.
- `loltrends` is not importable here yet; `riot_client.py` is a documented vendored mirror (ADR-0001, ADR-0008). Swap when a wheel exists.

## Collaboration

- Decision questions go one at a time through the question tool, always with a recommendation.
- Commit only after the four gates pass; never commit `.env` or `data/`.
